# 08 — GLOSSARY

Vocabulary of PRIMORDIA. Terms are load-bearing: using them precisely is
part of the engineering.

---

**Moment-Machine** — a temporary software organism assembled live from capabilities to serve one goal; dissolves when the goal dies. The OS's core primitive.

**Cell** — one capability binding inside a moment-machine (a function/tool plus its budget).

**Capability Sea / Registry** — the indexed collection of everything a machine could possibly be assembled from.

**Organism** — a persistent software entity in Eden: genome + running instances + fitness history. Born from promotion of a proven moment-machine (or import).

**Genome** — an organism's heritable definition: behavior (Nebulara code), params (strategy knobs), memory_seed. The unit of evolution.

**Metabolism** — resource consumption model. Organisms/machines must earn tokens, CPU, memory by being useful; starvation is the default death.

**Fitness** — measured real-world usefulness (retention, success rate, reach). Never a committee's opinion.

**Mutation** — heritable change applied at reproduction: param jitter, structural fork, or LLM semantic mutation.

**Fossil Record** — the archive of extinct organisms with epitaphs and extracted lessons. Feeds future mutations. Nothing truly disappears.

**Speciation** — emergence of divergent organism populations serving distinct niches. A Stage 4 milestone.

**Promotion** — the act by which a recurring moment-machine becomes a permanent organism. The only path to persistence.

**PRIM-IR** — Primordia Intermediate Representation; the single source of truth between source and bytecode.

**Round-Trip Guarantee** — normative contract that source → IR → source preserves semantics. Makes decompilation rendering instead of reverse-engineering.

**Dark Binary** — any executable whose behavior cannot be recovered to readable form. Forbidden on Primordia by construction.

**META Block** — language-level provenance annotation attached to definitions; survives all compilation transforms.

**Provenance** — the embedded, queryable record of what code is, where it came from, what it intends.

**Self-Hosting** — the state where Nebulara compiles Nebulara. Stage 3 summit.

**Bootstrap Ladder** — the staged migration plan from C++ host toward full self-hosting (docs/07-ROADMAP.md).

**Hosted Era vs Metal Era** — development while Primordia runs as a program on Windows/POSIX (Stages 0–3) versus booting bare metal (Stage 5).

**The Pond** — a local, bounded biosphere instance. First Eden deployments are ponds; oceans come later.

**Epitaph** — structured cause-of-death recorded at extinction (`starved`, `outcompeted`, `dissolved`, `veto`).
