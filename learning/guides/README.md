# Nebulara Guides

Step-by-step walkthroughs for getting things done. Unlike the manuals
(reference) and cookbook (recipes), these are **procedures** — do this, then
that — for the most common tasks.

| Guide | What it walks you through |
|-------|---------------------------|
| [Getting Started (Setup)](setup.md) | Get an interpreter, run your first program |
| [Interactive REPL](repl.md) | Explore and probe with the interactive shell |
| [Modules & the Standard Library](modules.md) | Use `std/*.nbs` without tripping on build limits |
| [The Toolchain](toolchain.md) | Run, build, transpile, check, analyze a project |
| [Troubleshooting](troubleshooting.md) | Diagnose errors and the "does it run?" checklist |
| [IDE & Editor Tips](ide.md) | Edit, highlight, and navigate `.nbs` files |

---

## One rule guides them all

> **The shipped binary is truth.** Before trusting any feature you read about,
> probe it: run a tiny test file. (Every guide shows the probe pattern.)

---

## Start here

New to Nebulara? Read [Getting Started](setup.md). Then open the
[course](../course/README.md) or the beginner e-book to learn the language,
and keep this section for when you need "how do I do X" procedures.
