# Nebulara From Zero

## A Foundation-First Guide to the AI-Native Universal Programming Language

**Book 1 of the Nebulara Library** — for complete beginners.

---

## About this book

*Nebulara From Zero* assumes you have never written a line of code, or are new
to Nebulara specifically. It builds understanding from first principles: how a
program thinks, how Nebulara expresses that, and how you write small programs
with confidence.

This is a **book**, not a sprint. Read each chapter slowly; type every example;
do the "Try it" sections. The companion [Course](../course/README.md) is the
fast, exercise-driven track; this book is the deeper, explain-more companion.

**Audience:** absolute beginners, students, and developers coming from another
language who want the full story.

**What you need:** the Nebulara interpreter (see Chapter 1). Nothing else.

---

## How to read the code

All code blocks are `.nbs` files. Save them as `example.nbs` and run with your
interpreter:
```bash
nebulara example.nbs
```

We use the **newest** interpreter in the repo — on Windows:
`Compiler\nebulara.exe`. (More on this in Chapter 1.)

## The principles this book teaches

1. **Programs are instructions** — a recipe the computer follows exactly.
2. **Values flow** — data is created, transformed, and printed.
3. **Structure first** — decisions, loops, and functions organize that flow.
4. **Fail informatively** — guard your programs and read errors.
5. **Build, then grow** — every chapter ends with something you can run.
